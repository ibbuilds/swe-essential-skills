# Popular workflow coverage — 26 October 2026

See the [broader source audit](broad-workflow-coverage.md) for the subsequent
16-repository mechanism review beyond this three-author catalog.

This is a finite, auditable inventory: 38 Matt Pocock, 7 Ras Mic and 25 Addy Osmani
entrypoints at pinned revisions, not an assertion that every useful skill on the
internet has been implemented. Names can be wrappers around the same method.
The table maps the useful mechanism to its maintained owner; it does not promise
every upstream script, helper, integration or stylistic rule. Full metadata is in
[workflow-coverage.json](workflow-coverage.json).

**existing** means the mapped procedure already exists; **extended** identifies
this pass's explicit interview, questionnaire, domain-language or manual-setup
route; **host-specific** separates a general method from an unbundled tool adapter;
**out-of-scope** and **experimental** are not counted as implemented equivalents.
These are static coverage judgments, not 70 executed behavioral tests.

The authoring basis is [OpenAI's scoped skills guidance](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)
and [Anthropic's authoring guidance](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices).
The prior [expert comparison](expert-comparison.md) records official OpenAI/Anthropic,
Superpowers, Spec Kit, OpenSpec, GSD and specialist Vercel/Supabase/Trail of Bits/
HashiCorp mechanisms and exact revisions. That specialist work is reused within
its stated scope; it is not a fresh exhaustive census of those repositories.

## Explicit request routes

- “Grill my software plan”: software-requirements → design-interview. Reuse the
  plan; challenge consequential assumptions, ask ready decisions at the requested
  pace and carry accepted answers forward. This also applies to an accepted plan.
- “Draft questions for the stakeholder”: requirements for software contracts;
  PM task-coordination for cross-domain project decisions. Drafting is not sending.
- “Clarify our domain language”: requirements for meaning/acceptance; architecture
  for ownership boundaries and consequential design records.
- “Walk me through the setup only I can do”: construction → reproducible
  foundations. Do agent-capable work first; protect secrets and verify real state.
- A clear small change follows its existing implementation path without any of
  these interviews, extra documents, agent panels or tracker setup.
