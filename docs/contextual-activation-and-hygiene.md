# Contextual selection and bounded artifacts — 6 November 2026

All eighteen descriptions now expose task/symptom triggers and all eighteen
`agents/openai.yaml` policies explicitly allow implicit invocation. Construction
loads relevant installed specialists when actual failures, state/transaction,
trust-boundary, verification or delivery concerns arise, including mid-task.
Missing companions remain optional; accepted decisions and valid test evidence
carry across the transition.

Four long entrypoints disclose specialized detail conditionally while preserving
their mechanisms: construction, requirements, product definition and review.
Review lenses remain in a local reference; positioning and acceptance details
reuse existing local references. No new meta-skill, full-lifecycle mandate,
service or runtime dependency is introduced.

Construction also owns its generated artifacts and recovery copies, using its
existing reproducible-foundations reference. It prevents recursively nested
snapshots, stops unexplained output growth, scopes inspections and retires only
authorized task-owned regenerable scratch. PM workspace hygiene can complement
this work but is not required.

The original adaptations were checked against primary sources from
[Matt Pocock](https://github.com/mattpocock/skills/blob/4ae2317ddb22b046e26455e4f9c9b3aaaf62212d/skills/productivity/writing-for-agents/SKILL.md),
[Addy Osmani](https://github.com/addyosmani/agent-skills/blob/301b02b12bff98e4688e6984af6556802322bbde/skills/using-agent-skills/SKILL.md),
[Jesse Vincent / Superpowers](https://github.com/obra/superpowers/blob/22f0b463e7a5e579904dd6211a520321035526f7/skills/writing-skills/SKILL.md),
[OpenAI](https://developers.openai.com/blog/eval-skills) and
[Anthropic](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices).
No third-party prose or implementation was copied. Automatic selection and
lightweight execution are the user's requested contract; external mandatory
phase sequences and tool-specific assumptions are not imported.

Independent forward exercises used a supplied candidate catalog and natural
requests without skill names. A lost-response reservation repair selected
debugging, client engineering and verification: its regression failed before
repair, eight focused checks passed afterward, and the separate contract checker
confirmed effect count, draft preservation and post-reconciliation saving.
An export/backups task selected debugging, construction and PM hygiene,
produced the correct report while preserving user recovery, and retired only
authorized scratch. A one-label negative control loaded no candidate skill and
preserved its newline. These demonstrate bounded candidate loading/application,
not native host discovery rates, causal suite improvement or paid-model results.

The final metadata/reference check and 34 local tests pass. The invocation test
guards the shipped policy only; it cannot prove that a model selects a skill.
